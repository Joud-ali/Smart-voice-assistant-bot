# Smart-voice-assistant-bot
# مساعد صوتي ذكي باستخدام Gemini API 

## وصف المشروع
مشروع واجهة دردشة صوتية تعمل في المتصفح، تستخدم تقنيات Web Speech API لتحويل الصوت إلى نص، وتتواصل مع خادم PHP وسيط، الذي بدوره يرسل الطلبات إلى نموذج Gemini من Google ويعيد الردود النصية والصوتية.

## الخطوات المتبعة (Methodology)

1. **تصميم الواجهة الأمامية (Frontend)**
   - استخدام HTML5 و CSS3 لإنشاء واجهة مساعد ذكي بتصميم داكن حديث.
   - كتابة JavaScript (`app.js`) لتشغيل الميكروفون عبر `webkitSpeechRecognition`.

2. **تأمين الاتصال (Backend Proxy)**
   - إنشاء ملف PHP (`api/chat.php`) يعمل كـ Proxy (وسيط) لاستقبال طلبات المتصفح.
   - استخدام مكتبة cURL في PHP للاتصال الآمن بـ Google Gemini API مع إخفاء مفتاح API عن المستخدم.

3. **الحصول على المفتاح**
   - إنشاء مفتاح API من Google AI Studio واستخدامه في ملف PHP.

4. **النشر والاستضافة (Deployment)**
   - رفع الملفات على خادم InfinityFree مع التأكد من تفعيل SSL (HTTPS) لتمكين الميكروفون.
   - تنظيم الملفات بحيث تكون في المجلد الجذر، وملف `chat.php` داخل مجلد فرعي `/api`.
